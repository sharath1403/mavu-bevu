# Mavu Bevu — production frontend starter

This is the first production-oriented implementation of the supplied Mavu Bevu mockup.

## Included

- Responsive single-page layout
- Accessible semantic structure
- Desktop and mobile navigation
- Responsive service and impact grids
- Subtle hero animation
- Reduced-motion support
- Accessible contact form UX and validation
- SEO-friendly metadata
- No frontend framework or unnecessary runtime dependencies

## Before production

1. Confirm the GoDaddy hosting plan and current contact-form/email setup.
2. Replace the placeholder form submission in `main.js` with the approved GoDaddy/server endpoint.
3. Add final brand fonts and assets.
4. Add real Selected Work content when available.
5. Add favicon / social preview assets.
6. Test HTTPS, form delivery, mobile layouts, keyboard navigation and screen readers.

The current implementation intentionally does not invent a backend because the client's existing GoDaddy form/email setup still needs to be confirmed.
